# Educational project disclaimer

Reelhouse is an independent educational experiment in porting the behaviour of an iOS application to other platforms. The **KayakTime / DELvEK iOS application** is used as the example for reverse engineering and interoperability research. Reelhouse is a separate implementation, not an official port or a distribution of the original app. The UI design comes from **Claude Design (Anthropic)**; **Codex (OpenAI)** assists with implementation, investigation, testing, documentation and release automation, under the project owner’s direction and review.

The learning goals are to understand existing app behaviour, identify logic that can be shared between platforms, adapt interfaces and native capabilities to desktop and TV, and turn an AI-generated design handoff into a working implementation. The project also explores serverless clients, automated tests and repeatable builds. Human decisions, testing and review remain part of the process; generated output is not assumed to be correct.
