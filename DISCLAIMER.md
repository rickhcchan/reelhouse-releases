# Educational project disclaimer

Reelhouse is an independent educational and experimental project developed through reverse engineering and interoperability research on the **KayakTime / DELvEK iOS application**. The UI design comes from **Claude Design (Anthropic)**; **Codex (OpenAI)** assists with implementation, investigation, testing, documentation and release automation, under the project owner’s direction and review.

The learning goals are to translate an AI-generated design handoff into a working interface, understand existing API and app behaviour through bounded interoperability research, build a serverless client with reusable logic, and verify the result through automated tests and repeatable desktop builds. This is an experiment in combining design and coding tools with human decisions, testing and review, rather than treating generated output as automatically correct.
